# 로또 발매기

---
## 실행 결과 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해주세요.
1,2,3,4,5,6

보너스 번호를 입력해주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

---
## 기능 구현 목록 정의

### 입력
- [x] 구입 금액을 입력한다.(구입 금액을 입력 해주세요.)
  - 입력이 정수가 아닌 경우 예외 발생
- [ ] 당첨 번호를 입력한다.(당첨 번호를 입력 해주세요.)
- [ ] 보너스 번호를 입력한다.(보너스 번호를 입력해주세요.)

### 구입 금액 입력 검증
- [x] 구입 금액은 양의 정수이어야 한다.

### 당첨 번호 입력 검증
- [ ] 쉼표(,)를 기준으로 분리된다.
- [ ] 양의 정수이어야 한다.
- [ ] 1~45 사이어야 한다.
- [ ] 당첨 번호 사이에 중복된 숫자가 없어야 한다.

### 로또 머신
- [x] 로또 머신에 구입 금액을 넣으면, 로또 금액 당 1개의 코인을 구매한다.
  - 예외처리
    - 구입 금액이 로또 금액으로 나누어 떨어지지 않는 경우
- [x] 코인 한 개로 로또 한 개를 발행할 수 있다.
- [x] 발행 한 뒤 코인 한 개를 차감한다.

### 로또 숫자 생성
- [x] 무작위 정수 6개를 생성한다.
    - 중복이 없어야 한다.
    - 숫자는 1이상이어야 한다. 
    - 숫자는 45이하여야 한다.

### 로또 발행
- [x] 로또 한 개를 생성한다.
  - 예외처리
    - [x] 로또 숫자가 6개가 아닌 경우
    - [x] 로또 숫자가 1 미만인 경우
    - [x] 로또 숫자가 45 초과인 경우
    - [x] 중복된 숫자가 포함된 경우

### 로또 당첨 등수 계산
- [x] 당첨 번호 6개와 로또 번호 6개와 일치하는 개수를 구한다.
- [x] 일치 개수와 보너스 일치 여부로 등수를 판정한다.
    - 1등: 6개 일치
    - 2등: 5개 + 보너스 일치
    - 3등: 5개 일치
    - 4등: 4개 일치
    - 5등: 3개 일치
    - 2개 이하이면 꽝
- [x] 등수를 통해 당첨 금액을 계산한다.

### 보너스 번호
- [x] 보너스 번호를 한 개 생성한다.
  - 예외처리
    - 숫자가 1미만인 경우
    - 숫자가 45초과인 경우

### 로또 서비스
- [x] 구입 금액으로 여러 장의 로또를 발행한다.
- [x] 발행된 로또의 당첨 결과를 계산한다.
  - 각 로또 별로 당첨 번호와 일치하는 개수를 확인한다.
  - 보너스 번호 일치 여부를 판단한다.
  - 등수를 확인하고 등수별 당첨 개수를 확인한다.
- [x] 수익률을 계산한다.
  - `‘당첨금액/구입금액 * 100’`으로 수익률을 계산한다.
  - 수익률은 소숫점 둘째자리에서 반올림한다.

### 출력
- [ ]  `8개를 구매했습니다.`구매한 로또 개수를 출력한다.
- [ ]  `[x, x, x, x, x, x]` 로또 번호 6개를 출력한다.
    - 로또 번호는 정렬된 형태여야 한다.
- [ ]  당첨 통계를 출력한다.
- [ ]  총 수익률을 출력한다.
    - 수익률은 소숫점 둘째자리에서 반올림 한다.
