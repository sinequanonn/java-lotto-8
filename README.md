# 미션 - 로또

## 🚀 기능 요구 사항
- [x] 사용자로부터 구입금액을 입력받는다.
- [x] 로또 한 장의 가격은 1,000원이며, 구입금액이 로또 금액 단위로 나누어 떨어지지 않는 경우, 다시 입력 받는다.
- [x] 구입 금액만큼 로또를 발행한다.
- [x] 로또 번호의 숫자 범위는 1~45 사이이다.
- [x] 로또는 중복되지 않는 숫자 6개를 가진다.
- [x] 발행된 로또 개수를 출력한다.
- [x] 발행된 로또 번호를 대괄호(`[]`)안에 쉼표(,)로 구분하여 출력한다.
- [x] 사용자로부터 쉼표(,)로 구분된 당첨 번호 6개를 입력받는다.
  - 당첨 번호는 1~45 사이이고, 중복되지 않는다.
  - 중복되는 경우, 다시 입력 받는다.
- [x] 사용자로부터 보너스 번호를 입력받는다.
  - 보너스 번호는 1~45사이이다.
  - 당첨 번호와 중복된 경우, 다시 입력 받는다.
- [ ] 발행된 로또와 당첨 번호 및 보너스 번호를 비교하여 당첨 통계를 출력한다.
  - 당첨은 1~5등까지 있으며, 아래는 당첨 기준이다.
    ```aiignore
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
    ```
  - 당쳠 통계 출력 예시
    ```
    당첨 통계
    ---
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    총 수익률은 62.5%입니다.
    ```
- [ ] 총 수익률을 계산한다.
  - 수익률은 `(총 당첨 금액)/(구입금액) * 100`이며, 소수점 두 번째 자리에서 반올림한다.

- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
    ```
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ```
